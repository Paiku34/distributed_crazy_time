avvio di 3 terminali erlang:

========================================
  CLUSTER ERLANG — 3 NODI
========================================

PREREQUISITI:
- RabbitMQ deve essere avviato (terminale 1)

IMPORTANTE:
- Tutti i nodi devono usare lo STESSO cookie (-setcookie crazytime)
- Ogni nodo ha un nome diverso (-sname game1, game2, game3)
- Il nodo con il nome più alto vince l'elezione (game3 > game2 > game1)
- Tutti e 3 i nodi sono gia' nella config di app.src (peer_nodes),
  cluster_manager filtra automaticamente se stesso

NOTA: usare "rebar3 shell" (non "erl" diretto) perche' su Windows
il glob _build/default/lib/*/ebin NON espande e i moduli non vengono trovati.

--- Terminale 3 — Nodo 1 (game1@localhost) ---
   (in cmd.exe)

cd C:\Users\cacak\OneDrive\Desktop\distributed_crazy_time\erlang-engine\game_engine
set ERL_FLAGS=-sname game1@localhost -setcookie crazytime
escript ..\rebar3 shell

--- Terminale 4 — Nodo 2 (game2@localhost) ---
   (in cmd.exe)

cd C:\Users\cacak\OneDrive\Desktop\distributed_crazy_time\erlang-engine\game_engine
set ERL_FLAGS=-sname game2@localhost -setcookie crazytime
escript ..\rebar3 shell

--- Terminale 5 — Nodo 3 (game3@localhost) ---
   (in cmd.exe)

cd C:\Users\cacak\OneDrive\Desktop\distributed_crazy_time\erlang-engine\game_engine
set ERL_FLAGS=-sname game3@localhost -setcookie crazytime
escript ..\rebar3 shell

Se usi PowerShell al posto di cmd.exe, il comando per settare la variabile è:
  $env:ERL_FLAGS = "-sname game1@localhost -setcookie crazytime"
  escript ..\rebar3 shell

VERIFICA CLUSTER (dalla shell di qualsiasi nodo):
  nodes().                                %% nodi connessi (kernel)
  cluster_manager:get_connected_nodes().  %% stessa cosa via API
  cluster_manager:get_nodes().            %% tutti i peer configurati

NOTE:
- Puoi avviare i nodi in qualsiasi ordine
- Il cluster_manager ritenta il ping dei peer ogni 10 secondi
- Per ora (senza Fase 3) vedrai il log "leader_election non ancora disponibile"
  → è normale, l'elezione verrà aggiunta nella prossima fase
- Se vuoi usare solo 1 nodo come prima, usa il vecchio comando:
  escript ..\rebar3 shell
